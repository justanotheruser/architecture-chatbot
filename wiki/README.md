# Wiki по проекту Lexi

Lexi - хобби-проект телеграм-бота для коротких интерактивных историй, генерируемых LLM, для практики иностранных языков.
Wiki сгенерирована с помощью LLM по существующему коду/артефактам архитектуры.

## Как запустить

```
python -m venv .venv
source .venv/bin/activate
pip install mkdocs
mkdocs serve
```
